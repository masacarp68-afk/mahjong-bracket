# 麻雀トーナメント表

参加者の名前を貼り付けて抽選するだけで、麻雀の勝ち抜きトーナメント表を作れるWebアプリです。
`index.html` をブラウザで開けば使えます。インストールやサーバーは不要です。

## できること

- 名前をコピペして抽選(1行に1人。タブ・カンマ区切りも可)
- 各卓の上位2名が勝ち上がる表を決勝まで自動で作成
- 2回戦から出場するシードを名前で指定(任意。選ばなかった枠は抽選)
- 1位・2位を押すと、次の卓に名前が自動で入る
- 大会名とロゴの表示、ロゴの色から背景を作成(模様は4種類)
- 全体、2回戦まで、または回戦ごとに 1920×1080 のPNGで保存
- 入力内容はそのブラウザに自動保存(共有を始めるまで外部には送信しない)
- 共有リンクで、運営メンバーと同時に結果を入力

## 共有

表を作ったあと「共有を始める」を押すと、共有リンクが作られます。リンクを開いた人は、同じ表を見て結果を入力でき、内容は全員の画面に自動で反映されます。

- リンクを知っている人は全員、結果の変更や抽選のやり直しができます。運営メンバーだけに送り、SNSには載せないでください。
- 共有を始めると、参加者名、結果、大会名、ロゴがGoogleのサーバー(Firebase Realtime Database)に保存されます。
- 大会が終わったら「共有を終える」を押すと、サーバーから消えます。手元のブラウザには表が残ります。

データベースのアクセス制限は [database.rules.json](database.rules.json) にあります。変更したらFirebaseコンソールの「ルール」にも反映してください。

## 組み合わせのルール

- 16・32・64人のようにちょうどの人数でないときは、2回戦が 4・8・16・32・64人のどれかになるよう、1回戦に必要な卓だけを組みます。1回戦に出ない人が2回戦から出場するシードです(例: 40人なら1回戦4卓・シード24人)。
- 人数が奇数のときは、1回戦に3人打ちの卓が1つ入ります。
- 2回戦は1回戦の相手と当たらないように組みます。16・32・64人ちょうどのときは「A卓1位・B卓2位・C卓1位・D卓2位」の形です。シードがあるときは、勝ち上がった人が卓ごとに偏らないように分けます。
- 3回戦以降も再戦はできるだけ避けますが、決勝などでは避けられないことがあります。2回戦以降の結果で再戦になる卓には表示が出ます。

## テスト
