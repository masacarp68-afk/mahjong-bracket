# 麻雀トーナメント表

参加者の名前を貼り付けて抽選するだけで、麻雀の勝ち抜きトーナメント表を作れるWebアプリです。
`index.html` をブラウザで開けば使えます。インストールやサーバーは不要です。

## できること

- 名前をコピペして抽選(1行に1人。タブ・カンマ区切りも可)
- 各卓の上位2名が勝ち上がる表を決勝まで自動で作成
- 1位・2位を押すと、次の卓に名前が自動で入る
- 大会名とロゴの表示、ロゴの色から背景を作成(模様は4種類)
- 全体または回戦ごとに 1920×1080 のPNGで保存
- 入力内容はそのブラウザに自動保存(外部には送信しない)

## 組み合わせのルール

- 2回戦は「A卓1位・B卓2位・C卓1位・D卓2位」のように別々の卓の人を混ぜるので、13人以上なら1回戦の相手と当たりません。
- 人数の端数が1〜2人ならシード(その回は免除)、3人なら3人打ちの卓にします。
- 3回戦以降も再戦はできるだけ避けますが、決勝や一部の人数では避けられないことがあり、その場合は卓に表示が出ます。

## テスト

```bash
node test-bracket.js
```
